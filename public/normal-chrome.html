Sign in with normal Chrome.

Google may reject browsers controlled by automation. This path opens a dedicated, ordinary Chrome profile without Playwright, remote debugging or fingerprint changes. You sign in personally; an optional companion transfers only Google cookies to your encrypted local Hermo store.

  1. In Hermo Privacy, review Normal Chrome sign-in, authorize the Google cookie transfer and confirm your workspace password. Choose Open normal Chrome & create import code.
  2. In the new normal Chrome window, sign in to Google yourself. Complete any MFA or verification. Use this dedicated profile for one Google account; Google cookies can include every Google account signed into the profile.
  3. In that same Chrome window, open chrome://extensions, enable Developer mode, and choose Load unpacked. Select the companion/chrome folder in your Hermo project. Hermo shows its exact path below the import code. For Edge, use edge://extensions.
  4. Open the companion from Chrome's extensions menu. Enter the local Hermo address shown in your main browser (usually http://127.0.0.1:4318). Copy the one-use import code from Hermo Privacy into the companion.
  5. Review its authorization checkbox, then choose Allow Google access & transfer. Chrome asks for cookie access to the listed Google hosts. Approve only if you trust this local, reviewable extension.
  6. Return to Hermo Privacy and choose Check imported sign-in. Select it when connecting an app. Complete that app's login and confirm its account before testing/publishing an API.
The import code expires after ten minutes and is revoked when the workspace locks or the server restarts. Generate a new code if needed. The extension has no background collection, passwords, remote service, or whole-browser profile import. Removing a saved sign-in clears Hermo's copy and dependent connection states; it does not clear Google cookies in Chrome. Websites can reject reused cookies or require another verification. This path does not guarantee universal or permanent access.

If the companion cannot find your sign-in

After updating Hermo, open chrome://extensions in the same Chrome profile and choose Reload for the Hermo companion. Close and reopen the popup and check that its footer shows 0.1.1. Refreshing Hermo alone does not update the installed extension. This version includes exact google.com access needed to read shared Google sign-in cookies; approve it if Chrome prompts when you authorize transfer.

Use Open Google account in this profile in the popup and finish sign-in on that website in the same normal window. Signing in to Hermo or Chrome Sync alone does not confirm the website session. Reopen the companion and retry with a fresh import code. No other Chrome profiles or Incognito stores are scanned.

Security boundary

Normal Chrome uses its ordinary browser network and Chromium-managed profile storage. It does not use Hermo's isolated policy proxy during manual sign-in. Google cookies are copied only after your explicit transfer and saved using Hermo's encryption. Local storage, IndexedDB, other website sessions and Chrome Sync are not imported. Imported cookies are a draft sign-in aid, not proof of vendor account identity or permission to access a vendor API.
