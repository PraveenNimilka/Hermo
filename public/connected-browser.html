Connect once. Keep your setup.

Use a website in normal Chrome with your existing sign-in. No cookie import is needed.

First-time companion installation

Use Chrome 120 or newer. Open chrome://extensions, enable Developer mode, and choose Load unpacked. Select Hermo's companion/browser directory. Install it in each saved Chrome browser you want to use. For this update, reload companion 0.7.10 and close old controller tabs.

Connect your website

  1. In Hermo, go to Connections and choose a saved browser or save a new one. Enter the website and choose whether it requires an account.
  2. Open the website in that Chrome browser. Sign in personally if needed.
  3. Create and copy a Connect code in Hermo. Click the companion on the website tab.
  4. Paste the code, authorize the selected tab, and press Enter. Close the popup after connecting; the website now has a fixed Hermo panel with Stop. No extra tab is opened.
  5. Hermo automatically marks the selected tab Connected. No account name or email selection is required. Create an action when the website is ready.

See your actual website in Hermo

  1. Reload companion 0.7.10 in chrome://extensions, then reconnect the website tab.
  2. On that website tab, open the Hermo companion and choose Enable live preview. Chrome authorizes capture of this exact tab.
  3. Return to Hermo. The Website view shows the actual tab appearance and updates while the panel is open, including when the website is in the background. Use Detected fields for the simplified inspection.

With companion 0.7.10, click detected buttons in the live preview to operate and record them. Click a field to open its input editor, and scroll over the preview to scroll the website. Keyboard users can use Interact and the Scroll buttons. Changed or stale targets are rejected. There is no audio capture, visible controller tab or saved screenshot history. Choose Stop preview in the companion to stop sharing without disconnecting workflows. One tab can share a preview at a time. Sharing expires after 15 minutes or two minutes without preview requests; re-enable it in the companion when needed. Worker recovery never restarts visual sharing. Sign-in and verification pages pause delivery to Hermo.

Turn your task into an API

  • Chat and text: record the message input and submit control, then select the completed reply.
  • Generate media: record the generation task and select its finished image, video, audio, or download URL. A new asset is required for each run; allow up to five minutes for slow tasks.
  • Read data: select values such as temperature, location, prices or status. No input or click is required. Verify numbers, units and context; valid values may stay the same.
  • Search and extract: bind a query, record the search, and capture the records or links you need.
  • Submit and update: record form inputs and submission, then verify its confirmation. Review the website changes before approving replay.
  • Custom: combine the website controls and selected results needed for your own task.

These setup choices use the same recorded website engine. No provider API or paid-plan connection is needed. Use normal Chrome for tasks that generate media or submit forms; isolated browser replay supports retrieval tasks.

Test and publish your action. Its separate API key belongs in the app that calls your action, never in the companion popup. Keys stay in that app's memory and are cleared on reload. The generic action app accepts any inputs and displays selected text or asset links.

Repair a missing generated image result

First inspect the website: the original submission may already have generated an image. In the action's draft, open Edit workflow steps and extraction / Output mappings / Result targeting and choose Latest image result (or video/audio). This targets the latest media in an explicitly marked response or result log instead of one temporary element. Set the maximum run time as needed, save the draft, verify a new prompt, then publish. For a published action, choose Edit draft first. Existing published revisions remain unchanged. If the website has no supported result container, select its actual output or repair its selector manually. Selected page-local raster images can be captured as temporary local image links. Protected, canvas-only and unsupported media formats remain unavailable.

Review permissions and pause before changes

Before publishing, review the workflow's allowed origins, browser binding, recorded steps and output targets. This preview does not execute the website. In the step editor, select Pause for owner approval before this step for actions that need review. Earlier steps run normally. Open Test action or Runs to approve or reject the waiting step. API keys cannot approve; waiting holds the local queue and uses the total execution timeout. Earlier website changes are not undone.

Manage a workflow's keys under Test action / API keys. Revoke or rotate a selected key without disconnecting other workflows. Reload the companion and reconnect after updating; semantic role/name and label guards need companion 0.7.2. A unique CSS-only target can still change meaning, so review and repair older recordings.

Keep the local runtime available

You can close this dashboard. Keep the Hermo runtime process, computer and authorized Chrome tab available. The dashboard shows the unlock expiry; Lock, expiry or restarting the browser/runtime requires reconnection. A suspended extension worker can recover an idle connection. Work interrupted during a command is not repeated automatically.

Stop and return later

Stop on the website or in Hermo ends access and cancels active runs. Your saved browser, apps, actions and API keys remain. Reconnect the saved app when ready. Cancelling or revoking a key stops only its work. The tab remains available after any dispatched command is acknowledged; sibling workflows wait for that command to drain. If acknowledgement is lost or transport fails, Hermo ends the link at its deadline. A revoked key cannot read or resume its old runs. A submission already sent to a website cannot be recalled; inspect it before retrying an uncertain run.

Browser closure, workspace lock and lost links end active permission. Saved configuration remains on this device until deleted. Website sign-in may expire independently. Change browser profile restores a saved browser binding after extension reinstallation; runs use the account currently signed in to the selected tab; no account identity is pinned. Sign-in or verification must be completed on the website before recording or running.

Permissions and supported surfaces

The companion uses temporary access to the selected tab, scripting, and extension-owned storage for browser labels and temporary manual handoff metadata. The optional live preview adds tabCapture and offscreen permissions for the explicitly selected tab, without extra website host access or audio. Active grants and in-flight markers stay in trusted Chrome session storage and background memory, bounded by the workspace unlock lease; no cookies, passwords or API keys are copied from the website. Access is restricted to the selected origin; local Hermo pages are excluded except the sandbox.

Visible page controls and open shadow roots are supported. Cross-origin frames, closed shadow roots, canvas-only data and browser-internal pages require a different integration. Complete website verification personally in Chrome. If a website changes, reselect missing controls/outputs in Hermo rather than recreating the whole connection.
